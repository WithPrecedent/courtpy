    Identifies the judges in parsed cases and adds what is known about them.

    The federal rules find the names of the judges on each case as the opinion writes them, such as "LYNCH" and "R THOMPSON" (the "panel_judges", "authors", "concurring", and "dissenting" columns, with "; " between the names). To study the judges, each name has to be matched to a person. A Roster is a table of judges, with one row for each court that a judge has served on, which finds the judge that a name refers to from the court and year of the case.

    build_roster makes that table with the fjc-biographies package (https://github.com/WithPrecedent/fjc_biographies), from three files of the Federal Judicial Center's Biographical Directory of Article III Federal Judges (which download gets with it): the judges' service on each court, their demographics, and their careers before the bench. The rules in its "judges" rulebook code the careers, and another rulebook can be named, so they can be changed without changing courtpy. fjc-biographies also adds scores of the judges' ideology, which it gets from the judicial-common-space package (https://github.com/WithPrecedent/judicial_common_space): each appointment's Judicial Common Space score ("jcs") and the justices' Martin-Quinn scores ("mq_first", "mq_last", "mq_mean", and "mq_terms"):

    import courtpy

roster = courtpy.judges.Roster.from_fjc(jcs = True, martin_quinn = True)
roster.save()

    A saved roster is kept outside of projects (in "judges" in courtpy.utilities.data_folder()), where the techniques look for it when no roster is named. It is a CSV file, so judges and columns (such as a score of each judge's ideology) can be added to it in a spreadsheet. Every column of numbers or booleans that does not identify or date a judge's service is an attribute of the judge, which the techniques use.

    These techniques use a roster or the tables that it makes. They are added to the amos library as soon as courtpy is imported, so they can be named in settings. Cases and judges are different things, so the techniques are built from the mergers and shapers of amos, which join tables whose rows are not the same:

    • add_biography (an amos.Merger) adds what the roster says about each judge that each row names. Each row of Votes gets "judge_party", "judge_woman", and so on, and each row of Cases gets them for each seat of its panel: "judge_name1", "judge_party1", "judge_woman1", and so on for the first judge, "judge_name2" and the rest for the second.
    • add_jcs (an amos.Merger) is add_biography for each judge's Judicial Common Space score alone ("judge_jcs", or "judge_jcs1" and so on).
    • add_circuit (an amos.Merger) adds the median and total of the parties of the appointing presidents, and of the Judicial Common Space scores, of the active (not senior) judges of each case's circuit on the day it was decided.
    • code_panels (an amos.Munger) adds the composition of each case's panel: the share of its judges who are women, the mean party of the presidents who appointed them, and so on. It makes a row for each judge on each case (with lists_to_rows), finds the judges (with add_biography), and adds summaries of each case's judges to the case (with merge_summary).
    • cases_to_votes (an amos.Shaper) makes Votes: a table with one row for each judge on each case, with the judge's attributes, those of the other judges on the panel, and how the judge voted.
    • dockets_to_votes (an amos.Shaper) is cases_to_votes for Dockets: a row for each judge on each docket.
    • votes_to_cases (an amos.Shaper) undoes cases_to_votes: it makes Votes Cases again.
    • cases_to_judges (an amos.Shaper) makes Judges: a table with one row for each judge, which summarizes the judge's votes (with group_rows).
    • load_roster and download_biographies (reference loaders, see courtpy.loaders.ReferenceLoader) start a study of the judges themselves with a saved roster or one made from the Federal Judicial Center's files.

    The parts are in private modules: _names (how names are compared), _roster (the roster and its loaders), _biographies (AddBiography and AddJcs), _circuits (AddCircuit), and _panels (the techniques for panels and votes).

    Adds what a roster says about each judge that each row names.

    A name, as an opinion writes it (such as "LYNCH"), is matched to a judge in a roster (see Roster) with the court and year of the row's case, and the columns of the judge's row of the roster are added, with a prefix before their names. A name that is not matched gets missing values.

    In Votes (or any table with a row for each judge), each row names one judge ("judge"), so it gets "judge_party", "judge_woman", and so on. With "name" set to "author" and "prefix" to "author_", a table of cases gets what is known about the author of each opinion.

    In Cases, each case names several judges ("panel_judges", with "; " between the names), so the columns are numbered by each judge's seat (the place of the judge's name in the list): "judge_name1" (the judge's name, as the roster reports it), "judge_nid1" (the Federal Judicial Center's number for the judge), "judge_party1", "judge_woman1", and so on for the first judge, "judge_name2" and the rest for the second, for as many seats as the longest panel has. A name that is not matched leaves its seat missing, so the judges after it keep theirs. "judge_name" and "judge_nid" columns that the cases already have (from code_panels) are left as they are.

    Instead of a roster, "lookup" can be a function that takes a judge's name (as the opinion writes it), the number of the case's court, and its year, and returns what is known about the judge, by the names of its columns (or None if nothing is). Then "judge_name1" is the name as the opinion writes it.

    Like every merger of amos, it takes these parameters, never adds, removes, or reorders rows, and records how many rows it matched in the dataset's history:

    Parameter Meaning
    source The roster: the path of a saved one (looked for in the current folder and then in the clerk's input folder), a roster, or the table of one. Without it, the roster saved in "judges" in utilities.data_folder() is used.
    columns The columns to add. By default, they are the roster's attributes (see Roster.attributes) and those that depend on the case: "age", "senior", "designated", and "district_judge" (see Roster.describe). All of them are added as numbers (1 and 0 for true and false). Any other column of the roster can be named too, such as "judge" (the judge's name, as the roster reports it), "nid", or "president".
    prefix Text to put before the names of the added columns. It is "judge_" unless another is set.
    indicator The name of a column to make that says whether each row's judge was found (or, numbered, how many of its judges were).
    name, court, year The columns of the data with the judges' names and the number of the court and the year of the row's case. They are "panel_judges" (for Cases) or "judge", "court_num", and "year" unless others are set.
    numbered Whether each row names several judges, whose columns are numbered by their seats. Unless it is set, it is true for Cases without a "name", and false otherwise.
    lookup A function that finds what is known about a judge, used instead of a roster.

    self,
    item: amos.Dataset,
    *,
    source: Any = None,
    columns: Sequence[str] | str | None = None,
    prefix: str | None = 'judge_',
    indicator: str | None = None,
    name: str | None = None,
    court: str = 'court_num',
    year: str = 'year',
    numbered: bool | None = None,
    lookup: Lookup | None = None,
    **kwargs: Any) -> amos.Dataset:
    """Adds the columns of each judge that each row of `item` names.

    Args:
        item: the dataset to add columns to.
        source: the roster: a roster, the table of one, or the path of a
            saved one. Defaults to `None`, in which case the roster saved
            in "judges" in `utilities.data_folder()` is used. It is not
            used with `lookup`.
        columns: the columns to add: attributes of the judge (see
            `Roster.described`) or other columns of the roster (or, with
            `lookup`, names that it returns). Defaults to `None`, in
            which case they are every attribute (or, with `lookup`, every
            name that it returns).
        prefix: text to put before the names of the added columns.
            Defaults to "judge_".
        indicator: name of a column to make that says whether each row's
            judge was found, or (numbered) how many of its judges were.
            Defaults to `None`, which makes no such column.
        name: the column of `item` with the judges' names, as an opinion
            writes them. Defaults to `None`, in which case it is
            "panel_judges" if `numbered`, and otherwise "judge".
        court: the column of `item` with the number of the court of the
            row's case. Defaults to "court_num".
        year: the column of `item` with the year of the row's case.
            Defaults to "year".
        numbered: whether each row names several judges, separated by
            "; " (or in a list), whose columns are numbered by their
            seats. Defaults to `None`, in which case it is true if `item`
            is `Cases` and `name` is `None`.
        lookup: a function that takes a judge's name, the number of the
            case's court, and its year, and returns what is known about
            the judge (or `None`). Defaults to `None`, in which case the
            roster is used.
        **kwargs: not used.

    Raises:
        KeyError: if `item` lacks one of the columns `name`, `court`, and
            `year`, or one of `columns` is not in the roster.
        ValueError: if an added column would have the name of a column
            of the data.

    Returns:
        The dataset with the added columns. Its rows and index are not
            changed.

    """
    if numbered is None:
        numbered = isinstance(item, datasets.Cases) and name is None
    if name is None:
        name = 'panel_judges' if numbered else 'judge'
    if columns is None and self.default_columns is not None:
        columns = list(self.default_columns)
    data = item.data
    cases.require_columns(data, [name, court, year], repr(self.name))
    named = _listed(data, name, court, year) if numbered else pd.DataFrame({
        _ROW: np.arange(len(data)),
        _SEAT: 1,
        _WRITTEN: data[name].to_numpy(),
        court: data[court].to_numpy(),
        year: data[year].to_numpy()})
    if lookup is None:
        roster = self._roster(source)
        found, rows = self._from_roster(
            named, roster, columns, court = court, year = year)
        matched = rows >= 0
        identity = pd.DataFrame({
            'name': roster.data['judge'].reindex(rows).to_numpy(),
            'nid': roster.data['nid'].reindex(rows).astype(
                'Int64').array})
    else:
        found = _from_lookup(named, lookup, columns, court, year)
        matched = found.notna().any(axis = 1).to_numpy()
        identity = pd.DataFrame({
            'name': named[_WRITTEN].where(matched).to_numpy()})
    start = prefix or ''
    if numbered:
        identity = identity[[
            key for key in identity.columns
            if f'{start}{key}1' not in data.columns]]
        seated = pd.concat([
            named[[_ROW, _SEAT]].reset_index(drop = True),
            identity.add_prefix(start),
            found.add_prefix(start)], axis = 1)
        added = by_seat(seated, len(data))
        if indicator is not None:
            added[indicator] = pd.Series(matched).groupby(
                named[_ROW].to_numpy()).sum().reindex(
                    range(len(data)), fill_value = 0).to_numpy()
    else:
        added = found.add_prefix(start)
        if indicator is not None:
            added[indicator] = matched
    added.index = data.index
    clashes = [c for c in added.columns if c in data.columns]
    if clashes:
        message = (
            f'{self.name!r} would add columns named {clashes}, which the '
            f'data already has: set "prefix" to tell them apart, or name '
            f'the columns to add in "columns"'
        )
        raise ValueError(message)
    item.replace(pd.concat([data, added], axis = 1))
    item.record(
        self.name,
        source = (
            'lookup' if lookup is not None
            else str(source) if isinstance(source, str | pathlib.Path)
            else type(source).__name__),
        rows = len(data),
        judges = int(named[_WRITTEN].notna().sum()),
        matched = int(matched.sum()),
        created = list(added.columns))
    return item

    year: str = 'year',

    """Returns the row of a roster for the judge that each row names.

    Args:
        data: the data, with a row for each judge to find.
        other: a roster, or the table of one.
        name: the column of `data` with the judge's name, as an opinion
            writes it. Defaults to "judge".
        court: the column of `data` with the number of the court of the
            row's case. Defaults to "court_num".
        year: the column of `data` with the year of the row's case.
            Defaults to "year".
        **kwargs: not used.

    Raises:
        KeyError: if `data` lacks one of the columns.

    Returns:
        The position of the judge's row in the roster for each row of
            `data` (see `Roster.match`), or -1 if the name is missing or
            is not matched.

    """
    cases.require_columns(data, [name, court, year], repr(self.name))
    roster = Roster.create(other)
    named = zip(
        data[name].tolist(), data[court].tolist(), data[year].tolist(),
        strict = True)
    found = (
        roster.match(written, _whole(number), _whole(when))
        if isinstance(written, str) and written.strip() else None
        for written, number, when in named)
    return np.array(
        [-1 if row is None else row for row in found], dtype = 'int64')

    Adds the ideology of the active judges of each case's circuit.

    For a case of a court of appeals, the circuit is the court's own; for a case of a district court, it is the circuit of the court of appeals that hears its appeals (see courtpy.courts.circuits). The judges of the circuit are those of its court of appeals in a roster (see Roster) who were active on the day the case was decided: they had been appointed, had not left the court, and had not taken senior status (senior judges do not sit on the court en banc). Their scores are summarized:

    Column Meaning
    circuit_median_party The median party of the presidents who appointed them (-1 for Democratic and 1 for Republican).
    circuit_total_party The sum of those parties, which is how many more were appointed by Republicans than by Democrats.
    circuit_median_jcs The median of their Judicial Common Space scores (higher is more conservative).
    circuit_total_jcs The sum of their scores.
    circuit_judges How many judges were active.

    The scores of the Judicial Common Space are added if the roster has them (make it with Roster.from_fjc(jcs = True)). A judge without a score is left out of its summaries. A case whose circuit or date is not known (or whose circuit had no active judge in the roster) gets missing values.

    Like every merger of amos, it never adds, removes, or reorders rows, and records how many rows it matched in the dataset's history. It takes these parameters:

    Parameter Meaning
    source The roster: the path of a saved one, a roster, or the table of one. Without it, the roster saved in "judges" in utilities.data_folder() is used.
    columns The scores to summarize: "party", "jcs", or both (the default, if the roster has "jcs").
    date The column with the date each case was decided. It is "date_filed" unless another is set.
    court_num, court The columns with courtpy's number for each case's court and CourtListener's id for it. They are "court_num" and "court" unless others are set.
    prefix Text to put before the names of the added columns. It is "circuit_" unless another is set.

        f'{prefix}{kind}_{_SCORES[score]}': np.full(len(data), np.nan)

        if serving.empty:
            continue

        active = _is_active(serving, days)

    A table of judges that finds the judge a name in an opinion refers to.

    Each row of the table is a judge's service on one court, so a judge who was promoted from a district court to a court of appeals has two rows, with the president who made each appointment. Only judges who were serving in the year of the case (or had left their court no more than grace years before it) are considered. A name is matched by how much of a judge's name it gives, from the most to the least (see name_forms):

    1. a full name: one of the ways that fjc-biographies writes the judge's name (the "name_..." columns, such as "Sandra Lea Lynch", "Sandra L. Lynch", "Sandra Lynch", and each with any suffix), or one of the judge's "aliases",
    2. or else initials and the last name ("S. Lynch", "S. L. Lynch", "S.L. Lynch", or "S. Lea Lynch"), or the middle and last names ("Lea Lynch", for a judge who goes by a middle name),
    3. or else the last name alone, which is how opinions usually name judges.

    The first of them that fits any judge who was serving is used. A name that fits no judge at all is then tried in shorter forms, as a full name or initials (see shorter_names): an opinion's "Susan P. Graber" is "Susan Graber", and its "Ed Carnes" is "E. Carnes", but never the last name alone. Many judges share a name, especially a last name, so the judges whose names fit are then narrowed by the court of the case:

    1. to a judge of the case's court,
    2. or else to a judge of a district court in the case's circuit, who may sit on its court of appeals by designation,
    3. or else to a judge of any other court, such as a court of appeals or district court of another circuit, who may sit by designation.

    If more than one judge fits at the first step that any judge fits, the name is not matched, since there is no telling which judge was meant (candidates returns them all, so that other names on the case can tell them apart). A name that fits no judge at all is repaired, if it then fits exactly one judge: written without the damage that some opinions' text does to names ("P OSNER" for "POSNER"), or compared with the judges of the case's court for a scanning error ("KRAVTTCH" for "Kravitch"; see _repaired).     """

    columns = len(second) + 1

    for row in range(rows):
        table[row][0] = row

        first: the judge's first name.
        middle: the judge's middle name or names, which may be blank.
        last: the judge's last name.
        suffix: the suffix of the judge's name, such as "Jr." or "III".
            Defaults to an empty `str`.

    Returns:
        The forms of each level ("full", "initials", and "last"), as
            `clean_name` writes them, without repeats. There are none if
            `last` is blank.

    """
    first, middle, last, suffix = (
        clean_name(part) for part in (first, middle, last, suffix))
    levels: dict[str, list[str]] = {level: [] for level in _LEVELS}
    if not last:
        return levels
    written = {
        'full': [
            f'{first} {middle} {last}',
            f'{first} {middle[:1]} {last}',
            f'{first} {last}'],
        'initials': [
            f'{first[:1]} {middle} {last}',
            f'{first[:1]} {middle[:1]} {last}',
            f'{first[:1]}{middle[:1]} {last}',
            f'{first[:1]} {last}',
            # An initial alone is not a name that a judge goes by.
            f'{middle} {last}' if len(middle) > 1 else ''],
        'last': [last]}
    # Without a first name, a full name or initials would be the last name
    # alone, which belongs to the last level.
    alone = {last, f'{last} {suffix}'.strip()}
    seen: set[str] = set()
    for level, forms in written.items():
        for form in forms:
            for written_form in (form, f'{form} {suffix}' if suffix else ''):
                named = ' '.join(written_form.split())
                if not named or named in seen or (
                    level != 'last' and named in alone):
                    continue
                seen.add(named)
                levels[level].append(named)
    return levels

    data: pd.DataFrame,

    "judge_party1", "judge_party2", and so on (which `add_biography` adds to

        data: the cases.

            "panel_party" and "panel_found".

        The number of Republican appointees on each case's panel, as whole
            numbers, missing for a case whose panel is not of `size` judges
            whose parties are all known (as for a judge appointed by a
            president of another party).

    """
    seats = [f'judge_party{n}' for n in range(1, size + 1)]
    if all(c in data.columns for c in seats):
        parties = data[seats].apply(pd.to_numeric, errors = 'coerce')
        complete = parties.isin([-1, 1]).all(axis = 1)
        # A panel with more seats than `size` is a panel of another size.
        extra = f'judge_party{size + 1}'
        if extra in data.columns:
            complete &= pd.to_numeric(data[extra], errors = 'coerce').isna()
        counted = (parties == 1).sum(axis = 1)
        seated: pd.Series = counted.where(complete).astype('Int64')
        return seated.rename('republican_appointees')
    if 'panel_party' in data.columns and 'panel_found' in data.columns:
        party = pd.to_numeric(data['panel_party'], errors = 'coerce')
        found = pd.to_numeric(data['panel_found'], errors = 'coerce')
        counted = (found * (party + 1) / 2).round()
        averaged: pd.Series = counted.where(found == size).astype('Int64')
        return averaged.rename('republican_appointees')

        f'counting the Republican appointees of panels needs {seats} (from '
        f'add_biography) or "panel_party" and "panel_found" (from '
        f'code_panels)')
