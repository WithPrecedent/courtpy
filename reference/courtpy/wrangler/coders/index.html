    Techniques that code variables from parsed cases.

    code_parties, code_case_type, code_outcome, split_values, and tidy_cases are amos.Munger techniques, which change and add columns without adding or removing rows, and drop_text_columns is an amos.Cleaner, which removes columns. Each is added to the amos (and chrisjen) library as soon as courtpy is imported, and it can be named in the settings of any amos worker. courtpy's loaders (see courtpy.loaders) also run the coders named in their "coders" parameter (by default, code_parties, code_case_type, and code_outcome, in that order) right after parsing, so that a label such as "outcome_reversal" exists when the data is loaded.

    The coders use the columns made by the federal rules (such as "party1_appellant" and "disposition_reverse"). With other rules, make columns with the same names or write your own coder.

    Contents

    CodeCaseType: decides whether each case is criminal or civil, and its other types. CodeOutcome: decides whether each decision reversed the court below, and which side won. CodeParties: completes the roles of the parties. DropTextColumns: removes columns that models cannot use, such as text and lists. SplitValues: turns text with several values in each cell into lists or columns. TidyCases: gives columns of booleans or whole numbers with missing values types that allow them. code: applies coders (or other amos techniques) to parsed cases. _UNITED_STATES_FIRST: the pattern of a party's text that begins with the United States.

    CodeCaseType(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Munger

    Decides whether each case is criminal or civil, and its other types.

    A case is criminal ("type_criminal") if the United States is a party and there is a sign of a criminal case: a criminal docket number or history, a United States Attorney as counsel, or a criminal issue in the opinion (any "criminal_..." column). The United States is then the prosecution, and the other party is the criminal defendant. When both parties' text names the United States (as a caption that joins several appeals can: "Joseph Prochilo, Defendant, Appellee; United States of America, Appellant, v. Elvis Guerrero, Defendant, Appellee"), the party whose text ("party1" or "party2") begins with the United States is the prosecution, if only one does, and otherwise the party that is a defendant and not a plaintiff, if only one is, is the criminal defendant. Every other case is civil ("type_civil"), and its plaintiffs and defendants are coded as civil plaintiffs and defendants.

    Each other prefix of the rules of the topics of cases (see rules.case_type_prefixes: "tort", "contract", "ip", "writ", and "constitutional" in courtpy's rules) is a case type too: "type_tort" is true if any "tort_..." column is. So a case can be of several types (a civil case that is a tort case and a contract case), and a prefix added to the rules (such as "immigration_") is a type once the cases are parsed with it. cases_to_case_types makes a table of the types.

    Adds "type_criminal", "type_civil", "type_{prefix}" for each other prefix that a column of the cases has, and for each party, "party1_prosecution", "party1_criminal_defendant", "party1_civil_plaintiff", and "party1_civil_defendant" (and the same for "party2").

    Needs "party1_united_states", "party2_united_states", "party1_plaintiff", "party2_plaintiff", "party1_defendant", and "party2_defendant". Uses "docket_criminal", "counsel_us_attorney", and the "criminal_..." columns if they exist.

    def munge(
    self,
    data: pd.DataFrame,
    prefixes: Sequence[str] | str | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Codes the types of each case.

    Args:
        data: the parsed cases.
        prefixes: the prefixes of the columns of flags that are case
            types, other than "criminal" and "civil". Defaults to `None`,
            in which case they are those of courtpy's rules (see
            `rules.case_type_prefixes`).
        **kwargs: not used.

    Returns:
        The cases, with the new columns.

    """
    needed = [
        f'{side}_{role}' for side in ('party1', 'party2')
        for role in ('united_states', 'plaintiff', 'defendant')]
    _require_federal_columns(data, needed, self.name)
    signals = [
        c for c in data.columns
        if c in ('docket_criminal', 'counsel_us_attorney')
        or c.startswith('criminal_')]
    criminal_signal = pd.Series(False, index = data.index)
    for column in signals:
        criminal_signal |= cases.column_as_flags(data, column)
    government = (
        cases.column_as_flags(data, 'party1_united_states')
        | cases.column_as_flags(data, 'party2_united_states'))
    criminal = government & criminal_signal
    data['type_criminal'] = criminal
    data['type_civil'] = ~criminal
    chosen = (
        rules.case_type_prefixes() if prefixes is None
        else utilities.listify(prefixes))
    for prefix in chosen:
        flags = [c for c in data.columns if str(c).startswith(f'{prefix}_')]
        if prefix in ('criminal', 'civil') or not flags:
            continue
        found = pd.Series(False, index = data.index)
        for column in flags:
            found |= cases.column_as_flags(data, column)
        data[f'type_{prefix}'] = found
    united_states = _prosecuting_sides(data)
    for side, other in _SIDES:
        prosecution = criminal & united_states[side]
        data[f'{side}_prosecution'] = prosecution
        data[f'{side}_criminal_defendant'] = (
            criminal & united_states[other] & ~prosecution)
        data[f'{side}_civil_plaintiff'] = ~criminal & (
            cases.column_as_flags(data, f'{side}_plaintiff')
            | cases.column_as_flags(data, f'{other}_defendant'))
        data[f'{side}_civil_defendant'] = ~criminal & (
            cases.column_as_flags(data, f'{side}_defendant')
            | cases.column_as_flags(data, f'{other}_plaintiff'))
    return data

    CodeOutcome(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Munger

    Decides whether each decision reversed the court below, and who won.

    A decision is a reversal ("outcome_reversal") if it reversed, vacated, or remanded. The disposition in the header (or in CourtListener's data) is used when there is one, because the opinion may mention reversals that are not its own. Otherwise, the decision that the opinion states ("AFFIRMED." or "we reverse", which the federal rules find as "decision") is used. Only when there is neither are the opinion's words anywhere ("reverse", "vacate", or "remand") used, which may be about an earlier decision or a standard of review ("we will reverse only if").

    Then, for each party whose role is known (see CodeParties), the party won ("outcome_party1_won") if it brought the appeal and the decision was reversed, or it defended the appeal and the decision was not reversed. With CodeCaseType, the winner is also coded by side: "outcome_criminal_defendant_won", "outcome_prosecution_won", "outcome_civil_plaintiff_won", and "outcome_civil_defendant_won", and "appeal_by_defendant" says whether the (criminal or civil) defendant brought the appeal.

    Values that cannot be known (such as who won when neither party's role is known, or whether the criminal defendant won a civil case) are missing (pd.NA). Filter the cases before using such a column as a label (for example, with the filter_rows technique and the query "type_criminal").

    Needs "disposition_reverse", "disposition_vacate", "disposition_remand", "opinion_reverse", "opinion_vacate", and "opinion_remand". Uses "disposition", "decision", "decision_reverse", "decision_vacate", and "decision_remand", and the columns made by CodeParties and CodeCaseType, if they exist.

    def munge(self, data: pd.DataFrame, **kwargs: Any) -> pd.DataFrame:
    """Codes the outcome of each decision.

    Args:
        data: the parsed cases.
        **kwargs: not used.

    Returns:
        The cases, with the new columns.

    """
    rulings = ('reverse', 'vacate', 'remand')
    _require_federal_columns(
        data,
        [f'{p}_{r}' for p in ('disposition', 'opinion') for r in rulings],
        self.name)
    header = pd.Series(False, index = data.index)
    decision = pd.Series(False, index = data.index)
    opinion = pd.Series(False, index = data.index)
    for ruling in rulings:
        header |= cases.column_as_flags(data, f'disposition_{ruling}')
        decision |= cases.column_as_flags(data, f'decision_{ruling}')
        opinion |= cases.column_as_flags(data, f'opinion_{ruling}')
    reversal = header.where(
        _has_text(data, 'disposition'),
        decision.where(_has_text(data, 'decision'), opinion))
    data['outcome_reversal'] = reversal
    if not {'party1_appealing', 'party2_appealing'} <= set(data.columns):
        return data
    won = {}
    for side, _ in _SIDES:
        outcome = pd.Series(pd.NA, index = data.index, dtype = 'boolean')
        appealing = cases.column_as_flags(data, f'{side}_appealing')
        defending = cases.column_as_flags(data, f'{side}_defending')
        outcome[appealing] = reversal[appealing]
        outcome[defending] = ~reversal[defending]
        won[side] = outcome
        data[f'outcome_{side}_won'] = outcome
    categories = {
        'criminal_defendant': 'criminal_defendant',
        'prosecution': 'prosecution',
        'civil_plaintiff': 'civil_plaintiff',
        'civil_defendant': 'civil_defendant'}
    if all(f'party1_{c}' in data.columns for c in categories.values()):
        for name, column in categories.items():
            outcome = pd.Series(
                pd.NA, index = data.index, dtype = 'boolean')
            for side, _ in _SIDES:
                present = cases.column_as_flags(data, f'{side}_{column}')
                outcome[present] = won[side][present]
            data[f'outcome_{name}_won'] = outcome
        by_defendant = pd.Series(
            pd.NA, index = data.index, dtype = 'boolean')
        for side, _ in _SIDES:
            defendant = (
                cases.column_as_flags(data, f'{side}_criminal_defendant')
                | cases.column_as_flags(data, f'{side}_civil_defendant'))
            known = defendant & (
                cases.column_as_flags(data, f'{side}_appealing')
                | cases.column_as_flags(data, f'{side}_defending'))
            appealing = cases.column_as_flags(data, f'{side}_appealing')
            by_defendant[known] = appealing[known]
        data['appeal_by_defendant'] = by_defendant
    return data

    CodeParties(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Munger

    Completes the roles of the parties and finds who brought the appeal.

    A caption often gives one party's role but not the other's ("United States v. Smith, Defendant-Appellant"). Because the roles in each pair are opposites, a party is coded as an appellee if the other party is an appellant (and so on for petitioners and respondents, and for plaintiffs and defendants).

    It also adds "party1_appealing" and "party2_appealing" (the party brought the appeal) and "party1_defending" and "party2_defending" (the other party did). Each party's own caption decides first: a party is appealing if it is an appellant and not an appellee, and defending if the reverse. Only a party named neither appellant nor appellee is judged by whether it is a petitioner or respondent, since a habeas petitioner who won below is the appellee ("Petitioner, Appellee"). A party whose own caption decides nothing, or names it both (as a caption that joins several appeals can: "Joseph Prochilo, Defendant, Appellee; United States of America, Appellant, v. Elvis Guerrero, Defendant, Appellee"), takes the opposite of the other party's, if the other party's caption decides it. If both captions decide and agree, both are kept, and if they disagree (both appellants, as in a cross-appeal), both are unknown. Both are false for a party whose role is unknown.

    Needs the columns "party1_{role}" and "party2_{role}" for each role: appellant, appellee, petitioner, respondent, plaintiff, and defendant.

    def munge(self, data: pd.DataFrame, **kwargs: Any) -> pd.DataFrame:
    """Completes the roles of the parties.

    Args:
        data: the parsed cases.
        **kwargs: not used.

    Returns:
        The cases, with completed roles.

    """
    roles = [r for pair in _OPPOSITES for r in pair]
    needed = [f'{s}_{r}' for s in ('party1', 'party2') for r in roles]
    _require_federal_columns(data, needed, self.name)
    original = {c: cases.column_as_flags(data, c) for c in needed}
    for first, second in _OPPOSITES:
        for side, other in _SIDES:
            data[f'{side}_{first}'] = (
                original[f'{side}_{first}'] | original[f'{other}_{second}'])
            data[f'{side}_{second}'] = (
                original[f'{side}_{second}'] | original[f'{other}_{first}'])
    own = {side: _own_direction(original, side) for side, _ in _SIDES}
    for side, other in _SIDES:
        mine_appealing, mine_defending = own[side]
        other_appealing, other_defending = own[other]
        mine_known = mine_appealing | mine_defending
        other_known = other_appealing | other_defending
        agree = (
            (mine_appealing & other_defending)
            | (mine_defending & other_appealing))
        data[f'{side}_appealing'] = (
            (mine_appealing & (agree | ~other_known))
            | (~mine_known & other_defending))
        data[f'{side}_defending'] = (
            (mine_defending & (agree | ~other_known))
            | (~mine_known & other_appealing))
    return data

    def clean(
    self,
    data: pd.DataFrame,
    keep: Sequence[str] | str | None = None,
    label: str | None = None,
    groups: Sequence[str] = (),
    **kwargs: Any) -> pd.DataFrame:
    """Removes columns of text and lists.

    Args:
        data: the cases.
        keep: names of columns to keep even if they hold text. Defaults to
            `None`.
        label: name of the label, which is always kept. Defaults to
            `None`.
        groups: names of the group columns, which are always kept.
            Defaults to an empty tuple.
        **kwargs: not used.

    Returns:
        The cases, without text and lists.

    """
    names = [keep] if isinstance(keep, str) else list(keep or [])
    missing = [c for c in names if c not in data.columns]
    if missing:
        message = f'the columns {missing} are not in the data'
        raise KeyError(message)
    kept = {*names, *(c for c in [label, *groups] if c)}
    dropped = [
        c for c in data.columns
        if c not in kept and _is_text(data[c])]
    return data.drop(columns = dropped)

    SplitValues(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Munger

    Turns text with several values in each cell into lists or columns.

    Rules that find several values in a case (names, matches, and categories rules, such as "panel_judges", "citations_case", and "agencies") write them as text, with "; " between them. With "into" set to "lists" (the default), each cell becomes a list of its values, and a cell without values an empty list. With "columns", each value gets a column of its own, named for the column and the value's place ("panel_judges_1", "panel_judges_2", and so on, for as many values as the row with the most has), and the text is kept.

    To make a row for each value instead, use the lists_to_rows technique of amos (with "separator" set to ";").

    def munge(
    self,
    data: pd.DataFrame,
    columns: str | Sequence[str] | None = None,
    separator: str = cases._SEPARATOR,
    into: str = 'lists',
    **kwargs: Any) -> pd.DataFrame:
    """Splits the values of each cell of `columns`.

    Args:
        data: the cases.
        columns: names of the columns to split. Defaults to `None`, in
            which case they are the columns of the `names`, `matches`,
            and `categories` rules of the federal rulebook that are in
            the data.
        separator: the text between the values. Defaults to "; ", as the
            federal rules write them.
        into: "lists" or "columns". Defaults to "lists".
        **kwargs: not used.

    Raises:
        KeyError: if a column is not in the data.
        ValueError: if `into` is not "lists" or "columns".

    Returns:
        The cases, with lists in place of the text or with new columns.

    """
    if into not in _SPLIT_INTO:
        message = f'into must be one of {list(_SPLIT_INTO)}, not {into!r}'
        raise ValueError(message)
    if columns is None:
        names = [c for c in _several_values() if c in data.columns]
    else:
        names = utilities.listify(columns)
    _require_federal_columns(data, names, self.name)
    added: list[pd.DataFrame] = []
    for column in names:
        values = [
            cases.split_cell(v, separator) for v in data[column].tolist()]
        if into == 'lists':
            data[column] = pd.Series(
                values, index = data.index, dtype = object)
            continue
        wide = pd.DataFrame(values, index = data.index, dtype = object)
        wide.columns = [f'{column}_{n + 1}' for n in range(wide.shape[1])]
        added.append(wide)
    if added:
        data = pd.concat([data, *added], axis = 1)
    return data

    Gives columns of booleans or whole numbers with missing values a type.

    pandas stores a column of booleans with missing values (such as "published", which is unknown for some cases) as plain objects, and a column of whole numbers with missing values (such as "year") as decimals. Such columns become the "boolean" and "Int64" types, which allow missing values (see courtpy.cases.tidy). Tables that courtpy parses or loads are tidied already, so it is for tables made or changed in other ways.

    def code(
    data: pd.DataFrame | amos.Dataset,
    coders: str | Sequence[str] | None = options._DEFAULT_CODERS,
    *,
    parameters: Mapping[str, Mapping[str, Any]] | None = None) -> amos.Dataset:
    """Applies coders (or other `amos` techniques) to parsed cases.

    Args:
        data: the parsed cases, or a dataset of them (which is changed in
            place).
        coders: names of the techniques to apply, in order. Defaults to
            `options._DEFAULT_CODERS`. "none" (or `None`) applies none.
        parameters: parameters for the techniques, by their names. Defaults
            to `None`.

    Returns:
        A dataset of the coded cases, whose history records each technique:
            `Cases` made from a table, or the kind that the last shaper made
            (such as `Votes`, after "cases_to_votes").

    """
    dataset = (
        data if isinstance(data, amos.Dataset)
        else datasets.Cases.create(data))
    for name in utilities.listify(coders):
        if utilities.is_none_setting(name):
            continue
        kind = cast(
            'type[amos.Operation]',
            chrisjen.library.borrow(name, genre = 'operation'))
        settings = dict((parameters or {}).get(name, {}))
        technique = kind(parameters = settings)
        dataset = technique.apply(dataset)
    return dataset
