    Turns saved court opinions into a table, one row for each case.

    Parsing has three stages:

    1. A source (courtpy.sources.Source, such as CourtListener or Lexis-Nexis, or one that a study adds) reads each saved case into a Case with sections of text (such as "party", "judges", and "opinion") and information that needs no parsing (such as CourtListener's date filed).
    2. For Lexis-Nexis, the "lexis_nexis" rules find the sections of the header (see courtpy.lexis). CourtListener's sections come from its data.
    3. Rules find variables in the sections. The source's header rules (its header, such as "lexis_nexis_header": the parties, their roles, and the agencies among them, the court, the disposition, and the judges; see courtpy.rules.make_header_rules) and the "general" rules (the decision, procedure, and standards of review) are always applied, and then the rulebooks that are named (by default, the "federal" rules, which add citations, civil (with tort, contract, and intellectual property), constitutional, and criminal issues, and agencies; "citations", "civil", "constitutional", "criminal", and "agencies" can be named alone). Each rulebook has the rules of its "general" file and then those of its "federal" file, if there is one (see courtpy.rules).

    The rulebooks are those of amos (amos.parsers.Rulebook, and courtpy's own in courtpy.rules), which search a table of the sections of many cases at once, a row for each case and a column for each section.

    Every section except those whose names end in "_lines" is collapsed onto one line between stages 2 and 3, so that phrases broken across lines are found.

    With "keep_text", the table keeps the text of every section, so that parse_all (ParseAll) can parse the cases again after the rules change, without reading the saved files again.

    Contents

    ParseAll: finds information in text with rules, or parses cases again from their kept text with every rulebook that fits them. Parser: parses cases with rulebooks. find_files: returns the saved cases of a source in a folder. parse: parses a folder of saved cases into a table. logger: the module's logger, which reports parsing progress and cases that could not be parsed.

    Bases: ParseAll

    Finds information in text with rules, or parses cases again.

    This is amos's parse_all, which it replaces in the amos library: given "rules", it applies them as amos.parsers.ParseAll does. Given none, it parses the cases of a table again from the text of their sections, which the table has if they were loaded with "keep_text" (such as after a change to the rules). Each case is parsed with every rulebook that fits it: the header rules of its source (by its "source" column; see courtpy.sources.Source), the rules of options._REQUIRED_RULEBOOKS, and "rulebooks" (by default, those of the jurisdiction, options._DEFAULT_JURISDICTION). Then "author", "panel_size", "concurrences", "dissents", and "word_count" are made again.

    A value that the rules find replaces the table's. Where the rules find nothing, the table's value is kept, such as a CourtListener case's court from CourtListener's id for it.

    Args:
        data: the data to parse.
        rules: the rules to apply (see `amos.parsers.Rulebook.create`).
            Defaults to `None`, which parses the cases again with every
            rulebook that fits them.
        column: the column of text that rules with a blank `column`
            search, if `rules` is given. Defaults to "text".
        rulebooks: names of rulebooks (such as "federal" or "civil") or
            paths to CSV files of rules, applied to every case after its
            source's header rules and `options._REQUIRED_RULEBOOKS`, if
            `rules` is not given. Defaults to `None`, which applies
            `options._DEFAULT_JURISDICTION`.
        source: the source of cases with no "source" column (or a blank
            one), such as "courtlistener". Defaults to `None`, in which
            case they get only the header rules that fit every source.
        **kwargs: passed to `amos.parsers.ParseAll.parse` if `rules` is
            given.

    Returns:
        The data, with the columns that the rules make.

    """
    if rules is not None:
        return super().parse(data, rules = rules, column = column, **kwargs)
    return self._parse_again(data, rulebooks, source)

    @classmethod
def create(
    cls,
    rulebooks: str | pathlib.Path | Sequence[str | pathlib.Path] = (
        options._DEFAULT_JURISDICTION),
    *,
    keep_text: bool = False) -> Parser:
    """Returns a parser with the rules in `rulebooks`.

    The rules of `options._REQUIRED_RULEBOOKS` are always applied first
    (after the header rules of each case's source), whether or not they
    are named.

    Args:
        rulebooks: names of rulebooks (such as "federal" or "civil") or
            paths to CSV files or folders of them, applied in order.
            Defaults to `options._DEFAULT_JURISDICTION`.
        keep_text: whether to keep the text of the cases' sections in the
            table. Defaults to `False`.

    Raises:
        FileNotFoundError: if a rulebook is not the name of one, a CSV
            file, or a folder with CSV files.
        ValueError: if a file is missing a column or a row is not a valid
            rule. The message names the file and row.

    Returns:
        The parser.

    """
    if isinstance(rulebooks, str):
        rulebooks = utilities.listify(rulebooks)
    elif isinstance(rulebooks, pathlib.Path):
        rulebooks = [rulebooks]
    rulebook = amos.parsers.Rulebook.create(
        *options._REQUIRED_RULEBOOKS, *rulebooks)
    return cls(rulebook = rulebook, keep_text = keep_text)

    """Returns one row of the table for `case`.

    Args:
        case: the case to parse.

    Returns:
        The case's variables, by the names of their columns, with `None`
            for those that are missing (see `parse_cases`).

    """
    row = self.parse_cases([case]).iloc[0].to_dict()
    return {
        str(k): None if _is_missing(v) else v for k, v in row.items()}

    def parse_cases(self, found: Sequence[cases.Case]) -> pd.DataFrame:
    """Returns a table of `found`, with a row for each case.

    The cases of each source are parsed together, with every rule
    searching every case at once.

    Args:
        found: the cases to parse.

    Returns:
        The table, with a row for each case, in order, labeled 0, 1, 2,
            and so on. Information from a case's `metadata` comes first
            and is used instead of any variable of the same name that the
            rules find (unless it is missing).

    """
    groups: dict[str, list[int]] = {}
    for position, case in enumerate(found):
        groups.setdefault(case.source, []).append(position)
    tables = [
        self._parse_source([found[p] for p in positions]).set_axis(
            positions)
        for positions in groups.values()]
    if not tables:
        return pd.DataFrame()
    return pd.concat(tables).sort_index() if len(tables) > 1 else tables[0]

    def parse(
    files: pathlib.Path | str | Iterable[pathlib.Path | str],
    source: str = 'courtlistener',
    rulebooks: str | pathlib.Path | Sequence[str | pathlib.Path] = (
        options._DEFAULT_JURISDICTION),
    *,
    keep_text: bool = False,
    limit: int | None = None,
    workers: int = 1) -> pd.DataFrame:
    """Parses saved cases into a table, one row for each case.

    Columns with several values in a case (such as "panel_judges" and
    "citations_case") are text, with "; " between the values. The
    `split_values` technique (`coders.SplitValues`) turns them into lists or
    into a column for each value.

    Args:
        files: a folder of saved cases (searched with its subfolders), or the
            paths of saved cases.
        source: the name of the source the cases came from, such as
            "courtlistener" (the default) or "lexis_nexis" (see
            `courtpy.sources.SOURCES`).
        rulebooks: names of rulebooks (such as "federal") or paths to CSV
            files or folders of them. Defaults to
            `options._DEFAULT_JURISDICTION`.
        keep_text: whether to keep the text of the cases' sections in the
            table (see `ParseAll`). Defaults to `False`.
        limit: most cases to parse, for trying out rules. Defaults to `None`
            (every case).
        workers: number of processes to parse with. Defaults to 1.

    Raises:
        ValueError: if there is no source named `source`.

    Returns:
        The table, labeled by each case's id ("case_id"). A case that cannot
            be read is left out, with a warning.

    """
    reader = base.find_source(source)
    if isinstance(files, str | pathlib.Path):
        paths = reader.find_files(files)
    else:
        paths = [pathlib.Path(p) for p in files]
    if limit is not None:
        paths = paths[:limit]
    parser = Parser.create(rulebooks, keep_text = keep_text)
    labels: list[str] = []
    tables: list[pd.DataFrame] = []
    failures = 0
    outcomes: list[Any] = []
    for chunk_outcomes, table in _parse_all(parser, paths, reader, workers):
        outcomes.extend(chunk_outcomes)
        tables.append(table)
    taken: set[str] = set()
    for path, outcome in zip(paths, outcomes, strict = True):
        if isinstance(outcome, BaseException):
            failures += 1
            logger.warning('%s could not be parsed: %s', path, outcome)
            continue
        unique, number = outcome, 1
        while unique in taken:
            number += 1
            unique = f'{outcome}_{number}'
        taken.add(unique)
        labels.append(unique)
    logger.info(
        'parsed %d cases (%d could not be parsed)', len(labels), failures)
    tables = [t for t in tables if not t.empty]
    data = pd.concat(tables, ignore_index = True) if tables else pd.DataFrame()
    data.index = pd.Index(labels, name = 'case_id')
    return cases.tidy(data)
