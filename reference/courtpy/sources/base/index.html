    The base class for sources of court opinions.

    A Source is a kind of saved case that courtpy can read and parse, such as the JSON files that CourtListener's bulk data and API are saved as ("courtlistener") or the text files of Lexis-Nexis ("lexis_nexis").

    A source adds itself to courtpy when it is subclassed, as amos techniques add themselves to the amos library, so a study can add its own by defining a subclass in a module that it imports:

    import dataclasses
from typing import ClassVar

import courtpy


@dataclasses.dataclass
class StateCourtSource(courtpy.Source):

    name: ClassVar[str] = 'state_court'
    pattern: ClassVar[str] = '*.txt'

    def read(self, path):
        ...

    Then "state_court" can be the source of courtpy.parse and of a loader that subclasses courtpy.SourceLoader. A subclass with the name of one that is already known replaces it. A subclass that lists abc.ABC among its bases is a base class for others, and is not added.

    Source() dataclass ¶

    Bases: ABC

    Base class for a source of saved cases.

    A subclass writes read, which reads one saved case into a cases.Case, and sets pattern, which finds its saved cases in a folder. It is added to SOURCES when it is defined, under its name.

    Attributes:

    Name Type Description
    name str

    the name of the source, such as "courtlistener". Defaults to the snake case name of the class.
    pattern str

    the file pattern of its saved cases, such as "*.json".
    structure str | None

    the rulebook that finds the sections of its cases, if they need finding (such as "lexis_nexis"), or None.
    header str

    the rulebook that finds the court, the parties and their roles, and the judges in its cases' sections, which the parser applies before any other (see courtpy.rules.make_header_rules). Defaults to "header", which has only the rules that fit every source.

    def find_files(self, folder: pathlib.Path | str) -> list[pathlib.Path]:
    """Returns the saved cases in a folder and its subfolders.

    Args:
        folder: the folder.

    Returns:
        The paths of the files that match `pattern`, sorted. Files in
            hidden folders (such as ".courtpy", where downloads keep
            their place) are left out.

    """
    folder = pathlib.Path(folder)
    return sorted(
        p for p in folder.rglob(self.pattern)
        if p.is_file() and not any(
            part.startswith('.') for part in p.relative_to(folder).parts))

    def find_source(name: str) -> Source:
    """Returns a source of saved cases, by name.

    Args:
        name: the name of a `Source`, such as "courtlistener".

    Raises:
        ValueError: if no source has that name.

    Returns:
        An instance of the `Source` subclass.

    """
    if name not in SOURCES:
        message = f'source must be one of {sorted(SOURCES)}, not {name!r}'
        raise ValueError(message)
    return SOURCES[name]()
