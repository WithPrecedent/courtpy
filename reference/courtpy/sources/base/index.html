    Base classes for sources of court opinions and ways to download them.

    A Source is a kind of saved case that courtpy can read and parse, such as the JSON files that CourtListener's API and bulk data are saved as ("courtlistener") or the text files of Lexis-Nexis ("lexis_nexis"). A Download is a way to collect cases into a folder, such as from CourtListener's bulk data ("bulk") or its API ("api"), and saves them as one source.

    Both add themselves to courtpy when they are subclassed, as amos techniques add themselves to the amos library, so a study can add its own by defining a subclass in a module that it imports:

    import dataclasses
from typing import ClassVar

import courtpy


@dataclasses.dataclass
class OpinionsDownload(courtpy.Download):
    # The first line of the docstring is its help in "courtpy download".

    name: ClassVar[str] = 'opinions'

    def download(self, folder, *, courts = None, **options):
        ...

    Then "opinions" can be the "download" of load_court_listener and the way of courtpy download opinions. A subclass with the name of one that is already known replaces it. A subclass that lists abc.ABC among its bases is a base class for others, and is not added.

    Download(locate=pathlib.Path) dataclass ¶

    Bases: ABC

    Base class for a way to download cases into a folder.

    A subclass writes download, which saves the cases of some courts and dates in a folder as the source named by source, and can write add_arguments, which adds its own options to "courtpy download". It is added to DOWNLOADS when it is defined, under its name and each of its aliases.

    Settings from a settings file can be text (such as "true" or "500"), so download converts the options that it takes (see utilities.to_bool, utilities.to_date, and utilities.to_integer). It should ignore options that it does not take, which belong to other ways to download.

    the rulebook that finds the court, the parties and their roles, and the judges in its cases' sections, which the parser applies before any other (see courtpy.rules.make_header_rules). Defaults to "header", which has only the rules that fit every source.

    def find_files(self, folder: pathlib.Path | str) -> list[pathlib.Path]:
    """Returns the saved cases in a folder and its subfolders.

    Args:
        folder: the folder.

    Returns:
        The paths of the files that match `pattern`, sorted. Files in
            hidden folders (such as ".courtpy", where downloads keep
            their place) are left out.

    """
    folder = pathlib.Path(folder)
    return sorted(
        p for p in folder.rglob(self.pattern)
        if p.is_file() and not any(
            part.startswith('.') for part in p.relative_to(folder).parts))

    def find_download(name: str) -> type[Download]:
    """Returns a way to download cases, by name.

    Args:
        name: the name or an alias of a `Download`, in any case and with any
            spaces around it.

    Raises:
        ValueError: if no way to download has that name.

    Returns:
        The `Download` subclass.

    """
    key = str(name).strip().lower()
    if key not in DOWNLOADS:
        names = ', '.join(f'"{n}"' for n in _primary_names())
        message = f'download must be {names}, or "none", not {name!r}'
        raise ValueError(message)
    return DOWNLOADS[key]

    def find_source(name: str) -> Source:
    """Returns a source of saved cases, by name.

    Args:
        name: the name of a `Source`, such as "courtlistener".

    Raises:
        ValueError: if no source has that name.

    Returns:
        An instance of the `Source` subclass.

    """
    if name not in SOURCES:
        message = f'source must be one of {sorted(SOURCES)}, not {name!r}'
        raise ValueError(message)
    return SOURCES[name]()
