1"""Default settings for courtpy. 

2 

3These are module-level constants so that a project built on `courtpy` can 

4change them before they are used (for example, 

5`courtpy.options._MIN_INTERVAL = 2.0` to slow down requests to the 

6CourtListener API). Tables of the federal courts and the presidents are in 

7"instructions/federal" (see `courtpy.courts` and `courtpy.politics`). 

8 

9Contents: 

10 _API_URL: base address of the CourtListener REST API (version 4). 

11 _BULK_PREFIX: folder of the CourtListener bulk data in its bucket. 

12 _BULK_URL: address of the public bucket with CourtListener's bulk data. 

13 _CHUNK_SIZE: number of saved cases given to a process at a time when 

14 parsing with several processes. 

15 _COURT_GROUPS: names for groups of CourtListener court ids. 

16 _DATA_SUBFOLDER: the folder of the `amos` workspace's data folder that 

17 holds courtpy's downloads. 

18 _DEFAULT_CODERS: techniques that code variables after cases are parsed. 

19 _DEFAULT_JURISDICTION: rulebooks used when none are named. 

20 _REQUIRED_RULEBOOKS: rulebooks applied to every case, after its 

21 source's header rulebook and before those that are named. 

22 _DOCKET_SKIPPED: fields of a CourtListener docket that are not kept with 

23 a saved case. 

24 _ENV_API_KEY: environment variable that can hold the API key. 

25 _ENV_CONFIG: environment variable that can name the configuration folder. 

26 _ENV_DATA: environment variable that can name the data folder. 

27 _IDB_CIRCUITS: the Federal Judicial Center's Integrated Database's code 

28 for the circuit of each CourtListener court of appeals. 

29 _IDB_FIRST_YEAR: the first year of the Integrated Database's records of 

30 appeals. 

31 _JUDGE_GRACE: years after a judge leaves a court in which an opinion may 

32 still name the judge. 

33 _KEYRING_SERVICE: name under which the API key is kept in a keyring. 

34 _KEYRING_USERNAME: user name under which the API key is kept. 

35 _LARGE_SECTIONS: sections of text that are not kept in a case table 

36 unless asked. 

37 _MAX_WAIT: most seconds to wait when the API asks for a pause. 

38 _MIN_INTERVAL: fewest seconds between requests to the API. 

39 _OPINION_FIELDS: opinion fields requested from the CourtListener API. 

40 _PDF_DELAY: seconds between requests for opinions' PDFs to one court's 

41 website. 

42 _SCDB_FILES: the part of the name of each file of the Supreme Court 

43 Database that courtpy uses, by what `courtpy.scdb` calls each. 

44 _SCDB_LINK: the words of the links to those files on the page of a 

45 release of the Supreme Court Database. 

46 _SCDB_PAGE: address of the page that links to the releases of the 

47 Supreme Court Database. 

48 _SCDB_RELEASE: pattern for the address of the page of a release of the 

49 modern Supreme Court Database. 

50 _SOURCES: sources of court opinions that courtpy can read. 

51 _TEXT_FIELDS: CourtListener fields with the text of an opinion, in the 

52 order they are preferred. 

53 _TIMEOUT: seconds to wait for a response from a server. 

54 _USER_AGENT: how courtpy identifies itself to servers. 

55 

56""" 

57
