1"""courtpy's rulebooks, which find information in the text of court opinions. 

2 

3The rules are rows of CSV files (spreadsheets) in courtpy's "instructions" 

4folder, so they can be read and changed without knowing Python. They are 

5`amos` rulebooks: each row is a rule of `amos.parsers.ParseAll`, which 

6documents the columns and kinds of rules (and also reads files in the older 

7layout, with "target", "variable", "label", and "section"). 

8 

9The rules of each topic (such as "criminal") are in two places. The file in 

10the "general" folder has the rules that fit opinions of any jurisdiction, and 

11the file of the same name in a jurisdiction's folder (such as "federal") has 

12the rules that fit only that jurisdiction, if there are any. A rulebook for a 

13topic applies the general rules and then the jurisdiction's (see 

14`find_rule_files`). courtpy reads only federal cases so far, so every 

15rulebook here is federal. 

16 

17Each source's rules are in its folder of "sources" (such as 

18"sources/lexis_nexis"): the rules that find the sections of its cases, with 

19a file for each kind of court (such as "federal_appellate.csv"; see 

20`find_structure_file`), and the rules of its header ("header.csv"). The 

21header rulebook of a source (see `make_header_rules`) applies 

22"general/header.csv" (the rules that fit every source), rules made from the 

23jurisdiction's "agencies.csv" that find the agencies named in each party and 

24the history (see `make_agency_rules`), the source's "header.csv", and, for a 

25source whose cases name their court in text, rules made from the 

26jurisdiction's "courts.csv" that find "court_num" and "court_name" (see 

27`make_court_rules`). Rules made from "courts.csv" also find the court whose 

28decision is reviewed in every source's history ("lower_court_num" and 

29"lower_court_name"). 

30So the header rules name no courts or agencies of their own, and a court or 

31agency added to the tables is found without changing them. 

32 

33`register_rulebooks` makes a rulebook of each topic, a subclass of 

34`amos.parsers.ParseAll` that is added to the `amos` library, so it has a name 

35that `courtpy.parse`, the "rulebooks" of a case loader, other rulebooks, and 

36the "rules" of `parse_all` can use (such as "federal" or "civil"). Each is 

37also a technique of its own (such as `parse_civil`), which searches the 

38columns of text of a dataset (such as "opinion", which a case loader keeps 

39with "keep_text"). A study can make rulebooks of its own folders of rules the 

40same way. courtpy's own are in `RULEBOOKS`: "general", 

41"citations", "civil", "constitutional", "criminal", "review", "agencies", 

42"federal" (all of those, in that order), the header rulebooks "header" (for 

43a source with no rules of its own), "courtlistener_header", and 

44"lexis_nexis_header", and "lexis_nexis", which finds the sections of a 

45Lexis-Nexis case. The parser applies a source's header rulebook (named by 

46its `header`) before the others. 

47 

48Rules that make several values in one cell (`names`, `matches`, and 

49`categories` rules, such as "panel_judges", "citations_case", and 

50"agencies") separate them with "; ", so that a table of cases can be saved 

51as a CSV file. The `split_values` technique (`coders.SplitValues`) turns 

52such text into lists or columns. 

53 

54Contents: 

55 RULEBOOKS: courtpy's rulebooks, by their names. 

56 case_type_prefixes: returns the prefixes of the names of the rules of 

57 the topics of cases, each of which is a case type. 

58 find_rule_files: returns the files of rules of a topic in a jurisdiction. 

59 find_structure_file: returns the file of rules that finds the sections 

60 of a source's cases. 

61 make_agency_rules: returns rules that find the agencies named in 

62 sections of the header. 

63 make_court_rules: returns rules that find a case's court from its 

64 name. 

65 make_header_rules: returns the rules of a source's header. 

66 register_rulebooks: makes a rulebook of each topic in folders of rule 

67 files. 

68 _AGENCY_COLUMNS: the sections of the header whose agencies are found. 

69 _PARTY_AGENCY_END: what must follow an agency's name in a party. 

70 _PARTY_COLUMNS: the sections of the header that are parties. 

71 _CASE_TYPE_TOPICS: the topics whose rules' prefixes are case types. 

72 _COURT_NAME_COLUMNS: the columns of a table of courts with patterns of 

73 their names, in the order they are tried. 

74 _GENERAL: the folder of the rules that fit every jurisdiction. 

75 _HEADER: the stem of the files of header rules. 

76 _LOWER_COURT_LEVELS: the levels of courts, in the order they are tried, 

77 that the history is searched for to find the court whose decision is 

78 reviewed. 

79 _INSTRUCTIONS: courtpy's "instructions" folder. 

80 _JURISDICTION: the jurisdiction of the cases that courtpy reads. 

81 _SOURCES: the folder of the rules of each source. 

82 _TOPICS: the topics of courtpy's rules, in the order of the "federal" 

83 rulebook.

104# The sections of the header whose agencies are found, each into a column of 

105# its own ("party1_agencies" and so on), so a study can tell an agency that 

106# is a party from one whose decision is reviewed. 

107_AGENCY_COLUMNS: tuple[str, ...] = ('party1', 'party2', 'history') 

108# An agency that is a party is named as a party of its own, so its name ends 

109# the party or comes before a comma ("..., Respondent"), a semicolon (between 

110# parties), a closing parenthesis, or "et al." A name followed by other words 

111# is part of another party's name (such as "FMC WYOMING CORPORATION"). 

112_PARTY_AGENCY_END: str = r'(?=\s*(?:[,;)]|\.?\s*$|(?i:et\s+al)\b))' 

113# The sections of the header that are parties, whose agencies must end a party 

114# (see `_PARTY_AGENCY_END`). 

115_PARTY_COLUMNS: tuple[str, ...] = ('party1', 'party2') 

116# A court is found by how opinions name it before the Federal Judicial 

117# Center's names for it, which opinions rarely use. 

118_COURT_NAME_COLUMNS: tuple[str, ...] = ('opinion_name', 'fjc_name') 

119# The courts whose decisions the courts of appeals review. The history of an 

120# appeal also cites earlier appeals and remands from the Supreme Court, which 

121# are not the court below, so courts of appeals and the Supreme Court are left 

122# out. (A CourtListener case of the Supreme Court has the court below from its 

123# docket.) 

124_LOWER_COURT_LEVELS: tuple[str, ...] = ('trial', 'specialty') 

125# The folder of the rules of each jurisdiction is named for it. courtpy reads 

126# only federal cases so far. 

127_JURISDICTION = 'federal' 

128# The topics whose rules find the subject of a case. The prefix of each rule's 

129# name (such as "tort" in "tort_negligence") is a case type. 

130_CASE_TYPE_TOPICS: tuple[str, ...] = ('criminal', 'civil', 'constitutional') 

131# The topics of the built-in rules, in the order of the "federal" rulebook. 

132# The header rules are not among them, since they depend on the source (see 

133# `make_header_rules`). 

134_TOPICS: tuple[str, ...] = ( 

135 'general', 'citations', 'civil', 'constitutional', 'criminal', 'review', 

136 'agencies')

230def make_agency_rules( 

231 jurisdiction: str | None = _JURISDICTION, 

232 columns: Sequence[str] = _AGENCY_COLUMNS, 

233 party_columns: Sequence[str] = _PARTY_COLUMNS) -> list[dict[str, Any]]: 

234 """Returns rules that find the agencies named in sections of the header. 

235 

236 Each rule of the jurisdiction's "agencies" files (see `find_rule_files`) 

237 is made into a rule for each of `columns`, which searches only that 

238 column and makes "{column}_agencies" (such as "party1_agencies"), so 

239 that the header names no agencies of its own. In a column of 

240 `party_columns`, an agency's name must end a party (see 

241 `_PARTY_AGENCY_END`), so that a company or person named for an agency is 

242 not taken for it. 

243 

244 Args: 

245 jurisdiction: the folder of the jurisdiction's rules, such as 

246 "federal". Defaults to `_JURISDICTION`. If it is `None`, only 

247 the general rules are read. 

248 columns: the sections to search. Defaults to `_AGENCY_COLUMNS` 

249 ("party1", "party2", and "history"). 

250 party_columns: the sections of `columns` that are parties. Defaults 

251 to `_PARTY_COLUMNS` ("party1" and "party2"). 

252 

253 Returns: 

254 The rules, as `dict`s with the columns of a file of rules, ordered by 

255 column and then by the order of the files. They are empty if 

256 there are no "agencies" files. 

257 

258 """ 

259 try: 

260 paths = find_rule_files('agencies', jurisdiction) 

261 except FileNotFoundError: 

262 return [] 

263 tables = [ 

264 utilities.read_csv(path, dtype = str, keep_default_na = False) 

265 for path in paths] 

266 made: list[dict[str, Any]] = [] 

267 for column in columns: 

268 for table in tables: 

269 for row in table.to_dict('records'): 

270 rule = {str(key): value for key, value in row.items()} 

271 rule.update(column = column, name = f'{column}_agencies') 

272 if column in party_columns: 

273 rule['pattern'] = ( 

274 f'(?:{rule["pattern"]}){_PARTY_AGENCY_END}') 

275 made.append(rule) 

276 return made

279def make_court_rules( 

280 jurisdiction: str = _JURISDICTION, 

281 column: str = 'court', 

282 *, 

283 prefix: str = '', 

284 levels: Sequence[str] | None = None) -> list[dict[str, Any]]: 

285 """Returns rules that find a case's court from its name. 

286 

287 Each court of the jurisdiction's table of courts (see 

288 `courtpy.courts.court_table`) gives two `category` rules for each 

289 pattern of its names: one makes "{prefix}court_num" (its number) and the 

290 other "{prefix}court_name" (its `court`, such as "tenth_circuit"), if 

291 the pattern matches, ignoring case. Every court's "opinion_name" is 

292 tried before any court's "fjc_name". Within each, the courts are tried in 

293 the order of `levels`, and then in the order of the table (the courts 

294 of appeals and the Supreme Court before the district courts, so that 

295 "DISTRICT OF COLUMBIA" does not take the D.C. Circuit's cases). 

296 

297 Args: 

298 jurisdiction: the folder of the jurisdiction's instructions, such as 

299 "federal". Defaults to `_JURISDICTION`. 

300 column: the section with the name of the court. Defaults to "court". 

301 prefix: text put before the names of the columns that the rules make 

302 (such as "lower_" for the court whose decision is reviewed). 

303 Defaults to "", which makes "court_num" and "court_name". 

304 levels: the levels of courts (as in the table's "level") to try, in 

305 order. Courts of other levels are left out. Defaults to `None`, 

306 which tries every court in the order of the table. 

307 

308 Returns: 

309 The rules, as `dict`s with the columns of a file of rules. They are 

310 empty if the jurisdiction has no table of courts. 

311 

312 """ 

313 try: 

314 table = courts.court_table(jurisdiction) 

315 except FileNotFoundError: 

316 return [] 

317 if levels is not None: 

318 rank = {level: place for place, level in enumerate(levels)} 

319 table = table[table['level'].isin(rank)].sort_values( 

320 'level', key = lambda found: found.map(rank), kind = 'stable') 

321 made: list[dict[str, Any]] = [] 

322 for names in _COURT_NAME_COLUMNS: 

323 for number, name, pattern in zip( 

324 table['court_num'], table['court'], table[names], 

325 strict = True): 

326 if pd.isna(pattern) or not str(pattern).strip(): 

327 continue 

328 note = f'From the {names} of {name} in courts.csv' 

329 for made_name, value in ( 

330 ('court_num', str(number)), ('court_name', str(name))): 

331 made.append({ 

332 'column': column, 

333 'name': f'{prefix}{made_name}', 

334 'kind': 'category', 

335 'pattern': str(pattern), 

336 'value': value, 

337 'flags': 'ignorecase', 

338 'note': note}) 

339 return made

387def register_rulebooks( 

388 *folders: pathlib.Path | str, 

389 topics: Sequence[str] | None = None, 

390 combined: str | None = None, 

391 prefix: str = '') -> dict[str, type[amos.parsers.ParseAll]]: 

392 """Makes a rulebook of each topic in folders of rule files. 

393 

394 Each CSV file in `folders` is a topic, named for its stem (such as 

395 "criminal" for "criminal.csv"). The rulebook of a topic applies the file 

396 of the topic in each folder that has one, in the order of `folders`, so 

397 a folder of general rules can come before a folder of a jurisdiction's 

398 rules. Each rulebook is a subclass of `amos.parsers.ParseAll`, which is 

399 added to the `amos` library, so settings and `courtpy.parse` can name it 

400 (such as "criminal"), and it is a technique of its own (such as 

401 "parse_criminal"). A study can call this with its own folder of rules: 

402 

403 ```py 

404 courtpy.rules.register_rulebooks(STUDY_FOLDER / 'instructions') 

405 ``` 

406 

407 Calling it again with the same names replaces the rulebooks. 

408 

409 Args: 

410 *folders: folders of CSV files of rules, in the order in which their 

411 rules are applied. "~" is the user's home folder. 

412 topics: the topics to make rulebooks of, in order. Defaults to 

413 `None`, which makes one of every file in `folders`, in 

414 alphabetical order. 

415 combined: the name of a rulebook that applies every topic, in the 

416 order of `topics` (such as "federal"). Defaults to `None`, which 

417 makes no such rulebook. 

418 prefix: text put before the name of each topic's rulebook (with "_" 

419 between), so that the topics of two jurisdictions can have 

420 rulebooks of their own (such as "texas_civil"). Defaults to "", 

421 which uses the names of the topics alone. 

422 

423 Raises: 

424 FileNotFoundError: if a topic of `topics` has no file in `folders`, 

425 or `folders` have no CSV files. 

426 

427 Returns: 

428 The rulebooks, by their names (as settings name them), in order, 

429 with the combined one (if any) last. 

430 

431 """ 

432 paths = [pathlib.Path(folder).expanduser() for folder in folders] 

433 found = sorted({ 

434 file.stem for path in paths if path.is_dir() 

435 for file in path.glob('*.csv')}) 

436 names = list(topics) if topics is not None else found 

437 if not names: 

438 searched = ', '.join(str(path) for path in paths) 

439 message = f'there are no files of rules in {searched}' 

440 raise FileNotFoundError(message) 

441 books: dict[str, type[amos.parsers.ParseAll]] = {} 

442 for topic in names: 

443 files = [ 

444 path / f'{topic}.csv' for path in paths 

445 if (path / f'{topic}.csv').is_file()] 

446 if not files: 

447 searched = ', '.join(str(path) for path in paths) 

448 message = f'there is no file of rules for {topic!r} in {searched}' 

449 raise FileNotFoundError(message) 

450 name = f'{prefix}_{topic}' if prefix else topic 

451 listed = ', '.join( 

452 f'"{file.parent.name}/{file.name}"' for file in files) 

453 books[name] = _make_rulebook( 

454 name, files, f'Applies the rules of {listed}.') 

455 if combined is not None: 

456 listed = ', '.join(books) 

457 books[combined] = _make_rulebook( 

458 combined, list(books.values()), 

459 f'Applies the rulebooks of every topic, in order: {listed}.') 

460 return books

466def _make_rulebook( 

467 name: str, 

468 rules: Any, 

469 summary: str) -> type[amos.parsers.ParseAll]: 

470 """Makes a rulebook and adds it to the `amos` library. 

471 

472 Args: 

473 name: the name of the rulebook, in snake case (such as "criminal"). 

474 Its class is named "Parse" and the name in camel case (such as 

475 `ParseCriminal`). 

476 rules: the rules, in any form that `amos.parsers.Rulebook.create` 

477 accepts (such as a list of files). 

478 summary: the first line of the class's documentation. 

479 

480 Returns: 

481 The rulebook, a subclass of `amos.parsers.ParseAll`. 

482 

483 """ 

484 class_name = 'Parse' + ''.join( 

485 part.capitalize() for part in name.split('_')) 

486 book = type(class_name, (amos.parsers.ParseAll,), { 

487 'rules': rules, 

488 '__doc__': summary, 

489 '__module__': __name__}) 

490 return dataclasses.dataclass(book)
