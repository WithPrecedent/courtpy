    Catalog¶

    This page lists courtpy's techniques and the columns that its rulebooks make. It is built from courtpy itself each time the documentation is built, so it is always current. A study's settings can name any of these techniques (see Building a Study).

    Techniques¶

    Genre Technique Module Does
    case_loader load_cases courtpy.wrangler.loaders Loads a dataset of cases saved by Cases.save, or a table of one.
    cleaner drop_text_columns courtpy.wrangler.coders Removes columns that models cannot use, such as text and lists.
    describer compare_with_idb courtpy.references.fjc_idb Compares a dataset with the Integrated Database's records of appeals.
    evaluator audit_coverage courtpy.critic.audits Compares the cases of each court in each year with the database's.
    evaluator audit_parsing courtpy.critic.audits Counts the cases that lack what the rules should find.
    evaluator audit_random_assignment courtpy.critic.audits Checks that the traits of cases are balanced across their panels.
    evaluator validate_coding courtpy.critic.audits Measures how often courtpy's coding agrees with another source's.
    inferer panel_effects courtpy.critic.inferers Estimates the effect of a judge's colleagues on the judge's vote.
    merger add_biography courtpy.references.judges Adds what a roster says about each judge that each row names.
    merger add_circuit courtpy.references.judges Adds the ideology of the active judges of each case's circuit.
    merger add_court_scores courtpy.references.scores Adds scores of each case's court from a table of them.
    merger add_executive courtpy.references.politics Adds the executive in power when each case was decided.
    merger add_high_court courtpy.references.politics Adds the ideology of the Supreme Court when each case was decided.
    merger add_idb courtpy.references.fjc_idb Adds the Integrated Database's record of each appeal by its docket.
    merger add_jcs courtpy.references.judges Adds the Judicial Common Space score of each judge that each row names.
    merger add_judge_scores courtpy.references.scores Adds scores of each judge of each row from a table of them.
    merger add_legislature courtpy.references.politics Adds the ideology of Congress when each case was decided.
    merger add_scdb courtpy.references.scdb Adds the Supreme Court Database's columns to each case.
    munger code_case_type courtpy.wrangler.coders Decides whether each case is criminal or civil, and its other types.
    munger code_outcome courtpy.wrangler.coders Decides whether each decision reversed the court below, and who won.
    munger code_panels courtpy.references.judges Adds the judges and the composition of each case's panel.
    munger code_parties courtpy.wrangler.coders Completes the roles of the parties and finds who brought the appeal.
    munger split_values courtpy.wrangler.coders Turns text with several values in each cell into lists or columns.
    munger tidy_cases courtpy.wrangler.coders Gives columns of booleans or whole numbers with missing values a type.
    parser parse_agencies courtpy.wrangler.rules Applies the rules of "federal/agencies.csv".
    parser parse_all courtpy.wrangler.parsers Finds information in text with rules, or parses cases again.
    parser parse_citations courtpy.wrangler.rules Applies the rules of "general/citations.csv".
    parser parse_civil courtpy.wrangler.rules Applies the rules of "general/civil.csv", "federal/civil.csv".
    parser parse_constitutional courtpy.wrangler.rules Applies the rules of "general/constitutional.csv".
    parser parse_courtlistener_header courtpy.wrangler.rules Finds the parties, their roles, and the judges in a CourtListener case.
    parser parse_criminal courtpy.wrangler.rules Applies the rules of "general/criminal.csv", "federal/criminal.csv".
    parser parse_federal courtpy.wrangler.rules Applies the rulebooks of every topic, in order: general, citations, civil, constitutional, criminal, review, agencies.
    parser parse_general courtpy.wrangler.rules Applies the rules of "general/general.csv".
    parser parse_header courtpy.wrangler.rules Finds the parties, their roles, and the judges in the header of a case from a source with no header rules of its own.
    parser parse_lexis_nexis courtpy.wrangler.rules Finds the sections of a Lexis-Nexis case of a federal court of appeals.
    parser parse_lexis_nexis_header courtpy.wrangler.rules Finds the court, the parties, their roles, and the judges in the header of a Lexis-Nexis case.
    parser parse_review courtpy.wrangler.rules Applies the rules of "federal/review.csv".
    plot cases_over_time courtpy.artist.plots Plots the number of cases of each court in each year.
    plot court_rates courtpy.artist.plots Plots the rate of a column in each court, as bars.
    plot idb_confusion_matrices courtpy.artist.plots Plots how the data agrees with the Integrated Database, by variable.
    plot idb_missing_differences courtpy.artist.plots Plots how the appeals that the data lacks differ, by group.
    plot issues_over_time courtpy.artist.plots Plots the number of cases with each issue in each court in each year.
    plot judge_network courtpy.artist.plots Plots the judges as a network of who sat with, or dissented from, whom.
    plot lower_court_rates courtpy.artist.plots Plots the rate of a column for each court below, by reviewing court.
    plot panel_composition courtpy.artist.plots Plots the rate of a column for each composition of the panel.
    plot trends_by_administration courtpy.artist.plots Plots the yearly rate of a column in each court, with presidents.
    reference_loader download_biographies courtpy.references.judges Downloads the Federal Judicial Center's files and loads their roster.
    reference_loader download_idb courtpy.references.fjc_idb Downloads the Integrated Database's files and loads its appeals.
    reference_loader download_jcs courtpy.references.jcs Downloads the published files of Judicial Common Space scores.
    reference_loader download_politics courtpy.references.politics Downloads the sources of the political context and loads its table.
    reference_loader download_scdb courtpy.references.scdb Downloads the Supreme Court Database and loads its cases or votes.
    reference_loader load_idb courtpy.references.fjc_idb Loads the Integrated Database's table of appeals for a range of years.
    reference_loader load_politics courtpy.references.politics Loads a table of the political context of each year.
    reference_loader load_roster courtpy.references.judges Loads the table of a roster of judges.
    reference_loader load_scdb courtpy.references.scdb Loads the Supreme Court Database's table of cases or of votes.
    shaper cases_to_case_types courtpy.wrangler.shapers Makes a table with one row for each case type.
    shaper cases_to_courts courtpy.wrangler.shapers Makes a table with one row for each court.
    shaper cases_to_dockets courtpy.wrangler.shapers Makes a table with one row for each docket number of each case.
    shaper cases_to_judges courtpy.references.judges Makes a table with one row for each judge (Judges).
    shaper cases_to_party_types courtpy.wrangler.shapers Makes a table with one row for each party type.
    shaper cases_to_votes courtpy.references.judges Makes a table with one row for each judge on each case (Votes).
    shaper dockets_to_cases courtpy.wrangler.shapers Makes a table of dockets a table of cases again.
    shaper dockets_to_votes courtpy.references.judges Makes a table with one row for each judge on each docket (Votes).
    shaper votes_to_cases courtpy.references.judges Makes a table of votes a table of cases again (Cases).
    source_loader load_court_listener courtpy.wrangler.loaders Collects, parses, and codes cases from CourtListener.
    source_loader load_lexis_nexis courtpy.wrangler.loaders Divides, parses, and codes cases downloaded from Lexis-Nexis.

    Sources and ways to download¶

    A loader's "download" (and courtpy download) can name any way to download, and courtpy parse --source any source. A study can add both (see Building a Study).

    Way to download Saves Does
    api courtlistener Downloads cases with the CourtListener API (a key is needed).
    bulk courtlistener Extracts cases from CourtListener's bulk data (no key needed).
    Source Files Does
    courtlistener *.json Reads cases saved by CourtListener or courtpy.bulk.BulkData.
    lexis_nexis *.txt Reads Lexis-Nexis cases saved one to a text file (see split).

    Rulebooks and their columns¶

    Each rulebook below can be named in the "rulebooks" of a loader or of courtpy.parse. "header" and "general" are applied to every case. The columns of a rulebook are those that its rules make, in the order of the rules; see the rules guide for what each kind of rule makes.
